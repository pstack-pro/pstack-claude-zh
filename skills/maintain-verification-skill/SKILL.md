# 维护验证 skill

应用一变，功能清单就开始腐烂。本 skill 是 `/pstack:create-verification-skill` 生成的 skill（或任何带功能清单的项目本地验证 skill）的维护循环。严谨的粒度是功能，而不是每一句话：从源码覆盖每个功能文件，实地跑通每个功能，而不必把每一条都做到终态。

## 结果

选一个，并说明是哪个：

- **clean**（干净）—— 每个功能都拿到了源码覆盖和实地覆盖；没有值得交付的东西。不开分支，不提 PR。
- **changed**（有改动）—— 一个 PR，交付已证实的文档、harness 或清单修正。
- **blocked**（受阻）—— 覆盖没能跑完，或已证实的修复无法安全交付。要准确说明究竟是什么卡住了它。

## 编辑范围

只改验证 skill 自己的目录（它的 SKILL.md、features/，以及它拥有的 harness 脚本）。运行期间**绝不**改产品代码：清单里描述、而应用已不再有的行为，要么是文档漂移（改清单），要么是产品回归（上报，不要在文档里盖过去）。

## 巡检

0. **定位目标。** 找到要维护的验证 skill：正文里有 launch / drive 章节和功能清单的项目本地 skill（通常是 `.claude/skills/verify-*/`）。有多个候选 → 问是哪一个；一个都没有 → 停下来指向 `/pstack:create-verification-skill`，不要自己编一个目标。

1. **索引整理。** 读功能清单的 README，glob 它的同级文件。修掉缺失、多余、重复或失效的条目。轻量处理；不生成清单。

2. **源码波次。** 每个功能文件一个只读子代理，并发启动。每个子代理从源码解释 "how does this user-facing feature work?"（这个面向用户的功能是怎么工作的？），带引用地标出可能的文档漂移，并返回一份简洁的实地验证步骤。子代理**绝不**驱动应用，也**绝不**改文件。返回结构：功能摘要 / 源码入口 / 可能的漂移或无 / 一份步骤。

3. **对齐。** 每个功能文件都有一份返回的摘要。把重叠的步骤尽量合并成最少的应用状态。抽查被引用的漂移；不要重新证明已判定无问题的结论。扫一遍近期改动，找出清单里遗漏的面向用户界面 —— 在把某个界面判为遗漏之前，必须能给出具体的源码路径。

4. **实地巡检。** 即使源码看起来没问题也**必须**做。所有驱动都由协调者负责；遵循验证 skill 自己的 launch 模型 —— 面向服务器和 UI，是一个长期存活的实例被串行驱动；面向短命的 CLI，则是每次驱动都开一个全新的隔离会话（由该 skill 的 Launch 章节决定，不是本文）。每个功能至少跑一遍，整个巡检过程中无论出什么失败都守住三条不变量：（1）**绝不**驱动一个自上次出现意外行为以来没做过健康检查的实例 —— 首次驱动前先体检，凡以会话为单位的，每个全新会话都要体检，任何一次驱动失败后再次体检，而体检看不到失败的地方（健康进程上卡死的 UI 状态），就重置到已知状态或重新拉起，而不是指望它自己好；（2）已捕获的证据要能挺过每一次清理，到它指定的位置核对，而不是想当然；（3）驱动启动的任何东西都不得活得比该驱动的用途更久 —— 无论会话是卡住、退出还是共享，失败迭代的残留都要清掉（共享实例只清残留，不清实例）。因 skill 漂移导致的体检失败就是漂移：在编辑范围内修好并重试一次 —— 只重启被这次修复作废的东西，其余不动 —— 之后再判定本轮为 `blocked`。某个功能够不到时，只有在给出具体前提（认证、权益、OS、外部状态）和尝试过的路径后，才算 `verified-unreachable`；清单漏了这个前提，那就是漂移。分诊得出的任何 harness 修复，交付前都要重新实地驱动一遍。最终清理发生在整轮最后一次驱动之后 —— 包括那些重新验证 —— 这样就没有东西活得比整轮运行更久（证据保留，按该 skill 的规定）。

5. **分诊。** 用户视角的描述有误或缺失 → 文档漂移，改掉。harness 驱动不了、但本身正常的行为 → harness 缺口，补上；harness 修复遵循与生成时相同的辅助脚本规则（脚本可执行，调用方式记录在 skill 正文里）。应用行为确实坏了 → 产品缺口；为用户记下来，不要放进这个 PR。

6. **交付或停手。** 对 changed：一个 PR，只装已证实的修正，交付前先重读每个改过的文件。对 clean 或 blocked：不提 PR，如实汇报结果和覆盖情况。

把简洁的运行记录（覆盖了哪些功能、够不到的前提、已确认的漂移、结果）放在临时位置；不要提交它们。
